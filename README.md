# 📄 PDF Template Builder

A visual drag-and-drop PDF template builder built with **React + TypeScript**  
Inspired by tools like Figma, but focused on **PDF layout design**.

---

## ✨ Features

- 🧱 Drag & drop elements on PDF canvas
- 📝 Add Text fields (edit, resize, style)
- 🖼️ Add Image elements
- 🔀 Multi-select (Shift + Click)
- 📐 Align & Distribute elements
- 🖱️ Resize with handles
- ⌨️ Delete elements using keyboard (Delete / Backspace)
- 🧭 Floating toolbar for text styling
- 📄 A4 PDF canvas size (595 × 842 px)

---

## 🛠️ Tech Stack

- **React**
- **TypeScript**
- **Zustand** (state management)
- **Tailwind CSS**
- **Vite**
